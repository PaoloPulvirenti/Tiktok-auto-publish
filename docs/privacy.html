Informativa sulla privacy

Ultimo aggiornamento: 10 settembre 2026

In breve

"tiktok-daily-poster" è uno strumento personale usato da una sola persona — il titolare dell'account TikTok collegato — per pubblicare sul proprio profilo. Non raccoglie dati di altri utenti, non ha visitatori, non usa cookie e non effettua alcuna profilazione.

Titolare del trattamento

Paolo Pulvirenti — paolo.pulvirenti31@gmail.com

Quali dati vengono trattati

Lo strumento tratta esclusivamente dati riferiti all'account del titolare:

  • Token di accesso e di aggiornamento TikTok, ottenuti tramite il flusso OAuth ufficiale dopo l'autorizzazione esplicita del titolare. Servono unicamente a caricare i video sul suo profilo.
  • Informazioni di base del profilo (identificativo dell'account, nome visualizzato, limiti di pubblicazione), lette tramite l'endpoint creator_info per verificare che la pubblicazione sia possibile.
  • Fotografie e didascalie preparate dal titolare per i propri post.

Non vengono trattati dati di follower, commenti, messaggi o di altri utenti TikTok.

Dove sono conservati

I token sono salvati in un file locale sul computer del titolare, con permessi di lettura riservati al suo utente, oppure — nel caso dell'esecuzione automatica — in un "secret" cifrato del repository GitHub del titolare. Non vengono trasmessi ad alcun server dell'autore: non esiste un server dell'autore. Le uniche destinazioni delle chiamate di rete sono le API ufficiali di TikTok, di Anthropic (per scrivere la didascalia) e di Google Gemini (per la generazione dell'immagine, quando attiva).

Comunicazione a terzi

Nessun dato viene venduto, ceduto o comunicato a terzi. I fornitori sopra citati trattano i dati che ricevono secondo le rispettive informative.

Conservazione

I token restano validi finché il titolare non revoca l'autorizzazione dalle impostazioni del proprio account TikTok, cosa che può fare in qualsiasi momento. La revoca rende immediatamente inutilizzabile lo strumento. I file locali possono essere cancellati in ogni momento eliminando tokens.json.

Diritti dell'interessato

Poiché l'unico interessato è il titolare stesso, l'esercizio dei diritti previsti dal GDPR (accesso, rettifica, cancellazione, limitazione, portabilità, opposizione) si realizza direttamente attraverso il controllo dei propri file e delle autorizzazioni nel proprio account TikTok.
