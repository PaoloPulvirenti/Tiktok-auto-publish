# reference/

Mettici **le foto delle tue borse vere**, quelle che hai già realizzato.

Sono le immagini che vengono allegate a ogni generazione: è da qui che il
modello prende il filato, il punto, i colori e la resa reale del tuo lavoro.
Senza almeno una foto lo script si ferma con un errore, invece di inventare
un uncinetto che non è il tuo.

Consigli pratici:

- formati accettati: `.jpg`, `.jpeg`, `.png`, `.webp`;
- vengono usate le **3 più recenti** (`gemini.maxReferenceImages` in `config.js`);
- foto nitide, luce naturale, borsa ben visibile e possibilmente un dettaglio
  ravvicinato del punto: è la texture che rende credibile il risultato;
- queste foto **vengono committate nel repo**, perché servono al workflow su
  GitHub Actions. Se il repo è pubblico, saranno pubbliche anche loro.
